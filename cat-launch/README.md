# 猫猫 · 头号冒险

无依赖的 HTML / JavaScript 平台跳跃 Demo。双击 `index.html` 即可在桌面浏览器运行，无需安装。三个文件需放在同一目录。

## 操作

- A / D 或左右方向键：移动。
- 空格：按下立即跳跃，合体与分离时均可用。
- 鼠标：任意角度瞄准，也可以 Q / E 调节角度。
- 合体时在游戏画面按住鼠标左键：蓄力，1.4 秒达到最大力度；松开：发射头部。按住越久力度越大；切走窗口会取消蓄力。
- Tab：分离后切换控制头部或身体。
- 头部与身体相碰：自动合体，发射后有短暂保护期。
- R：回到检查点；右上角按钮：完全重开。

踩中薄荷色开关永久开启桥梁，收集三颗星星，合体抵达右侧小屋。头部跳跃比身体更高。任一部分掉落会让两部分一起回到检查点，已收集星星和开启的桥梁保留。

本 Demo 面向有键盘和鼠标的电脑。瞄准虚线是无障碍物时的飞行预测，真实轨迹会受平台碰撞和空中移动影响。

## 上传 Git

将此目录的 index.html、style.css、game.js、README.md 上传到指定仓库即可。可选用 GitHub Pages 等静态网页服务运行。
