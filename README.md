# 小小跳跃 (Little Jump)

一个基于 HTML5 Canvas 的 2D 像素风游戏原型。

## 游戏机制

- **下半身（红色）**：负责移动（A/D键）
- **上半身/头（黄色）**：负责瞄准和发射火球
- **核心玩法**：通过分离上半身来解决谜题和闯关

## 操作说明（根目录原型）

以下操作仅适用于根目录 `index.html`。猫猫独立 Demo 的按键不同，见下方说明。

| 按键 | 功能 |
|------|------|
| **A/D** | 左右移动 |
| **空格** | 下半身跳跃，合体与分离时均可用；不负责蓄力或融合 |
| **鼠标移动** | 瞄准头部发射方向 |
| **鼠标左键** | 发射火球（始终从头部发射）|
| **合体时按住鼠标右键，松开** | 按住蓄力，松开后分离并发射上半身（抛物线）|
| **分离后靠近头部，按鼠标右键** | 融合（两部分中心距离小于 50 像素）|
| **S** | 按住压扁下半身；合体时头部随姿势降低，不调整抛头起点 |
| **R** | 获胜后重新开始 |

根目录原型没有 Tab 切换控制或相碰自动合体；A/D 和空格始终控制下半身。鼠标操作需在游戏画面内完成。

## 猫猫 · 头号冒险 Demo

独立试玩版，位于 `cat-launch/`，与根目录原型的操作不同：自由角度瞄准、空格按下立即跳跃、合体时按住鼠标左键蓄力并在松开时发射头部、Tab 切换控制，头部和身体相碰自动合体。包括星星收集、桥梁开关和检查点。

| 按键 | 功能 |
|------|------|
| **A/D 或 ←/→** | 移动当前控制的部分 |
| **空格** | 当前控制的部分落地时，按下立即跳跃；长按不会蓄力抛头 |
| **鼠标移动 / Q/E** | 合体时调整发射角度 |
| **合体时按住鼠标左键，松开** | 在游戏画面内蓄力，1.4 秒达到最大力度，松开后发射头部；切走窗口取消蓄力 |
| **Tab** | 分离后切换控制头部或身体；发射后默认控制头部 |
| **头部与身体相碰** | 自动合体（发射后有 0.45 秒保护期）|
| **R / 右上角重新开始按钮** | 回到检查点 / 完全重开 |

此版本没有左键火球、右键抛头或右键融合；W/↑ 也不是跳跃键。

- 在线试玩：[猫猫 · 头号冒险](https://elio0110.github.io/LittleJump/cat-launch/)
- 本地运行：用浏览器打开 `cat-launch/index.html`。
- 完整操作说明：[cat-launch/README.md](cat-launch/README.md)。
